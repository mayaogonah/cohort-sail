# Risk of self-harm and victimisation after traumatic brain injury in childhood and adolescence: a nationwide cohort study 

R/Quarto repository for the manuscript 'Risk of self-harm and victimisation after traumatic brain injury in childhood and adolescence: a nationwide cohort study' which is currently under peer review.

The reposity contains the code to estimate the association between pediatric traumatic brain injury and time to self-harm and victimisation, adjusting for sociodemographic and clinical factors. The [HTML file](https://mayaogonah.github.io/cohort-sail/) rendered from Quarto, outlines the key stages of analysis.

This study makes use of anonymised data held in the Secure Anonymised Information Linkage (SAIL) Databank. We would like to acknowledge all the data providers who make anonymised data available for research. SAIL Databank prohibits individual-level data from being publicly available. Researchers who are interested in replicating this study can apply to work with the data through [SAIL Databank](https://saildatabank.com/data/apply-to-work-with-the-data/). The study protocol was pre-registered on [SAIL Databank’s Data Use Register](https://saildatabank.com/data/data-use-register/) (project code 1478).
